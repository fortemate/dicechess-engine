# Documentation assets

`dicechess-tv-hotseat.png` is an unmodified screenshot from the public
[Dice Chess TV project](https://github.com/fortemate/dicechess-tv/blob/main/site/src/assets/screenshots/hotseat.png),
recorded on the Vega Virtual Device. The application is Fortemate's AGPL-3.0-only project.
The screenshot contains RhosGFX chess pieces (CC0); see the TV project's
[third-party notices](https://github.com/fortemate/dicechess-tv/blob/main/THIRD_PARTY_NOTICES.md).
It illustrates the integration, not physical Fire TV validation.
